# 🚀 COSMIC Cloud-Dev Template (Built via Cloud)

This is an open-source development template designed to help developers build and test applets for the new **System76 COSMIC Desktop Environment** written in Rust, entirely from the cloud.

## 💡 The Story Behind This Project
I am a passionate open-source developer. Currently, **I do not own a personal computer or hardware capable of local compilation.** 

Refusing to let this stop me, I built this entire project using **GitHub Codespaces** on a mobile device. 

My goal is two-fold:
1. To enable any developer around the world who lacks powerful hardware to start contributing to the **Pop!_OS** and **COSMIC** ecosystem instantly.
2. To build a community-driven power management applet for COSMIC laptops.

## 🛠️ How to Use (Zero Setup)
You don't need a Linux machine to test this. You can launch a fully configured Linux environment with Rust and COSMIC dependencies ready in one click:

## 🎯 Next Steps & Hardware Limitations
While this cloud environment is perfect for writing code and compiling Rust, **I cannot visually test the desktop applets or optimize them for real battery/hardware performance without physical device testing.**

I am looking to connect with the **System76 team** for a potential hardware grant or developer partnership to test this on real hardware (like a Lemur Pro or Oryx Pro) and take this ecosystem tool to the next level.
